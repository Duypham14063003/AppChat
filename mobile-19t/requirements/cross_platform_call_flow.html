1
NestJS gửi FCM push Firebase
Dùng firebase-admin để push notification tới device token của B. Payload đặc biệt — không phải notification thường.
firebaseAdmin.messaging().send({
token: calleeDeviceToken,

type: "INCOMING_CALL",
callId, callerId, callerName,
channelName, agoraToken,

"content-available": 1 // silent push iOS
}}}
})
2
iOS — CallKit thức dậy iOS Native
flutter_callkit_incoming nhận silent push → trigger native CallKit UI (màn hình gọi đến của iOS). Hoạt động ngay cả khi app bị kill.
FlutterCallkitIncoming.showCallkitIncoming(
CallKitParams(
id: callId,
nameCaller: callerName,
type: 0, // 0=audio, 1=video
duration: 30000,
)
)

Android — Custom incoming call UI Android
Android không có CallKit. Dùng flutter_callkit_incoming với custom notification (full-screen intent). Vẫn hoạt động khi app background/killed — FCM wake up app.

Media flow — Agora SFU làm trung gian
1
A capture audio → encode → gửi SFU Media
Windows mic capture → Agora SDK encode (Opus 48kHz) → UDP packets tới SFU edge server gần nhất (VN: Singapore).
// Agora tự handle — developer không cần config
// Latency Windows → Singapore SFU: ~30-50ms
2
SFU relay → B (iOS) Relay
SFU nhận stream của A → forward đến B. Không decode/re-encode (pure relay) → latency thấp. Tổng RTT thực tế: 60-120ms.
3
Adaptive bitrate — key feature Agora Auto
Agora SDK tự điều chỉnh bitrate theo bandwidth. iOS trên 3G yếu → SFU transcode xuống bitrate thấp hơn → không bị drop call.
// Không cần code gì — Agora tự handle
// Audio: 6kbps (bad) → 48kbps (good)
// Video: 100kbps (bad) → 1Mbps (good)
4
Cross-platform codec compatibility Key point
Windows (Flutter desktop) và iOS (Flutter mobile) dùng cùng agora_rtc_engine package. Agora SDK handle codec negotiation tự động — developer KHÔNG cần quan tâm tới Windows vs iOS vs Android vs Web.
