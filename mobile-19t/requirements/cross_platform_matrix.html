Những điểm kỹ thuật cần chú ý nhất
iOS — VoIP Push Certificate (quan trọng nhất)
iOS yêu cầu VoIP Push Certificate riêng (khác APN certificate thường) để wake app khi killed. Không có cert này → incoming call không hoạt động trên iOS khi app bị kill. Phải request trong Apple Developer Portal.
// flutter_callkit_incoming tự handle khi có cert
// Cần set trong Info.plist:
UIBackgroundModes: [voip, audio]
Android — Foreground Service bắt buộc
Android 12+ yêu cầu Foreground Service để giữ audio call khi app background. Không có → Android kill process → cuộc gọi bị ngắt sau ~1 phút.
// AndroidManifest.xml
<uses-permission android:name="android.permission.FOREGROUND_SERVICE"/>
<uses-permission android:name="android.permission.FOREGROUND_SERVICE_PHONE_CALL"/>
Token expiry — refresh mid-call
Agora token expire sau 3600s (1 giờ). Cuộc gọi dài hơn 1 giờ sẽ bị ngắt nếu không handle. Giải pháp: set token expire = 6 giờ, hoặc implement onTokenPrivilegeWillExpire để refresh.
engine.setEventHandler(RtcEngineEventHandler(
onTokenPrivilegeWillExpire: (token) async {
final newToken = await api.renewToken(channelName);
await engine.renewToken(newToken);
}
))
agora_rtc_engine — cùng 1 package, mọi platform
Đây là điểm mạnh nhất của stack Flutter + Agora. Code một lần, chạy trên iOS/Android/Windows/macOS/Web. Platform-specific chỉ ở phần incoming call notification — media logic hoàn toàn giống nhau.
// pubspec.yaml — một dependency duy nhất
agora_rtc_engine: ^6.5.3

// Cùng code cho mọi platform
await engine.joinChannel(token, channel, uid)
Web — giới hạn lớn nhất
Web app KHÔNG nhận được incoming call khi tab inactive hoặc browser đóng — FCM web push có giới hạn. Giải pháp: redirect user sang mobile/desktop app khi có cuộc gọi, hoặc keep web tab active với periodic ping.
