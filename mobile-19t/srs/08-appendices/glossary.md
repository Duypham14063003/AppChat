# 8.1 Glossary — Thuật ngữ

| Thuật ngữ | Tiếng Việt | Định nghĩa |
|-----------|-----------|-------------|
| 19T | Nineteen Tech | Tên công ty |
| Access Token | Token truy cập | JWT token ngắn hạn (15 phút) dùng để xác thực API requests |
| ACK | Xác nhận | Acknowledgement — server xác nhận đã nhận message |
| Agora SFU | — | Selective Forwarding Unit — server trung gian relay media cho voice/video call |
| BullMQ | — | Thư viện job queue cho Node.js, dùng Redis làm backend |
| Bunny.net | — | Dịch vụ CDN và object storage cho file/media |
| CallKit | — | Framework iOS cho native incoming call screen |
| CDN | Mạng phân phối nội dung | Content Delivery Network |
| Conversation | Cuộc hội thoại | Một phòng chat (DIRECT: 1-1, GROUP: nhóm, SAVED: tin đã lưu) |
| Cursor Pagination | Phân trang con trỏ | Dùng timestamp/ID làm mốc thay vì OFFSET |
| Drift | — | SQLite wrapper cho Flutter, dùng làm local cache |
| E2E | Đầu-cuối | End-to-End (encryption hoặc testing) |
| EARS | — | Easy Approach to Requirements Syntax — format viết yêu cầu |
| FCM | — | Firebase Cloud Messaging — dịch vụ push notification |
| FMEA | — | Failure Mode and Effects Analysis — phân tích rủi ro |
| FR | Yêu cầu chức năng | Functional Requirement |
| FTS | Tìm kiếm toàn văn | Full-Text Search |
| Geofencing | Hàng rào địa lý | Vùng GPS xác định, dùng cho auto-checkin |
| GIN Index | — | Generalized Inverted Index — loại index PostgreSQL cho FTS |
| JWT | — | JSON Web Token — chuẩn xác thực stateless |
| NFR | Yêu cầu phi chức năng | Non-Functional Requirement |
| Odoo | — | Hệ thống ERP mã nguồn mở, đang dùng tại erp.19t.vn |
| Optimistic UI | Giao diện lạc quan | Hiển thị kết quả ngay trước khi server xác nhận |
| OT | Tăng ca | Overtime — giờ làm vượt chuẩn |
| Partition | Phân vùng | Chia table thành nhiều phần vật lý (theo thời gian) |
| Pub/Sub | Xuất bản/Đăng ký | Pattern gửi message qua Redis channels |
| RBAC | Phân quyền theo vai trò | Role-Based Access Control |
| Refresh Token | Token làm mới | JWT token dài hạn (30 ngày) dùng để lấy access token mới |
| Riverpod | — | State management library cho Flutter |
| RPO | — | Recovery Point Objective — lượng data chấp nhận mất |
| RTO | — | Recovery Time Objective — thời gian khôi phục chấp nhận |
| SRS | Đặc tả yêu cầu phần mềm | Software Requirements Specification |
| SSO | Đăng nhập một lần | Single Sign-On |
| tsvector | — | Kiểu dữ liệu PostgreSQL cho full-text search |
| WebSocket | — | Giao thức real-time, persistent connection giữa client và server |
| WS | — | Viết tắt của WebSocket |
