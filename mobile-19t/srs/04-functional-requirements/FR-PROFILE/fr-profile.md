# FR-PROFILE — User Profile & Statistics

### PROF-FR-001 — Xem Profile cá nhân

- **Priority:** P0 🔴 MUST
- **Actor:** Employee
- **Description:** The system shall hiển thị profile cá nhân gồm: avatar, tên, email, phòng ban, chức vụ, ngày vào công ty (data từ Odoo).

### PROF-FR-002 — Thống kê chấm công

- **Priority:** P1 🟠 SHOULD
- **Actor:** Employee
- **Description:** The system shall hiển thị thống kê: tổng ngày công tháng này, OT hours, số ngày đi trễ, tỷ lệ đúng giờ. Dạng chart (bar/line).

### PROF-FR-003 — Thống kê nghỉ phép

- **Priority:** P1 🟠 SHOULD
- **Actor:** Employee
- **Description:** The system shall hiển thị: phép năm còn lại, phép đã dùng, phép ốm, breakdown theo tháng.

### PROF-FR-004 — Thống kê Task & Timesheet

- **Priority:** P1 🟠 SHOULD
- **Actor:** Employee
- **Description:** The system shall hiển thị: tổng giờ log tuần/tháng, tasks hoàn thành, tasks đang làm, productivity trend.

### PROF-FR-005 — Xem Profile người khác

- **Priority:** P1 🟠 SHOULD
- **Actor:** Employee
- **Description:** When user tap vào avatar/tên trong chat, the system shall hiển thị profile công khai: tên, avatar, phòng ban, chức vụ, online status. Không hiển thị data HR nhạy cảm.

### PROF-FR-006 — Cập nhật Avatar

- **Priority:** P1 🟠 SHOULD
- **Actor:** Employee
- **Description:** When user chọn đổi avatar, the system shall cho phép chọn ảnh từ gallery, crop, upload lên Bunny.net, và cập nhật profile.

### PROF-FR-007 — App Settings

- **Priority:** P0 🔴 MUST
- **Actor:** Employee
- **Description:** The system shall cung cấp settings: notification on/off, theme (dark mặc định), language (VI/EN), font size, sound on/off.

### PROF-FR-008 — App Version & Update Check

- **Priority:** P1 🟠 SHOULD
- **Actor:** System
- **Description:** The system shall hiển thị app version hiện tại và kiểm tra update. When có version mới bắt buộc (min_version), the system shall hiện force update dialog.
