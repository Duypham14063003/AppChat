# 7.3 Third-party Services

## 7.3.1 Agora.io — Voice & Video Call

| Config | Value |
|--------|-------|
| Service | Agora Real-Time Communication |
| SDK | `agora_rtc_engine` (Flutter) |
| Architecture | SFU (Selective Forwarding Unit) |
| Token | Generated by NestJS backend, TTL configurable |

**Integration points:**
- NestJS: `agora-access-token` npm package để generate RTC token
- Flutter: `agora_rtc_engine` package để join channel
- Token generation: `POST /calls/initiate` → NestJS tạo token với channel name + uid + role + TTL

**Pricing note:** Free tier: 10,000 minutes/month. Đủ cho < 50 users.

## 7.3.2 Bunny.net — File Storage & CDN

| Config | Value |
|--------|-------|
| Service | Bunny.net Storage + CDN |
| API | REST (PUT for upload) |
| Region | Asia (Singapore recommended) |

**Upload flow:**
1. Flutter chọn file → `POST /upload` (multipart) → NestJS
2. NestJS nhận file (multer) → stream upload tới Bunny.net Storage API
3. Bunny.net trả về URL → NestJS trả URL cho Flutter
4. Flutter gửi message với URL trong metadata

**API:**
```
PUT https://{region}.storage.bunnycdn.com/{storage_zone}/{path}/{filename}
Headers:
  AccessKey: {storage_api_key}
  Content-Type: application/octet-stream
Body: file binary
```

**CDN URL:** `https://{pull_zone}.b-cdn.net/{path}/{filename}`

**File organization:**
```
/chat/{conv_id}/{year}/{month}/{filename}
/avatars/{user_id}/{filename}
/hr/{type}/{filename}
```

## 7.3.3 Firebase Cloud Messaging (FCM)

| Config | Value |
|--------|-------|
| Service | Firebase Cloud Messaging |
| Backend SDK | `firebase-admin` (Node.js) |
| Flutter SDK | `firebase_messaging` |

**Setup:**
- Firebase project → download `google-services.json` (Android) + `GoogleService-Info.plist` (iOS)
- Service account key → NestJS backend
- APNs certificate → cho iOS push (required)

**Message types:**
- Notification message: hiện tự động khi app background
- Data message: app xử lý custom (dùng cho chat messages)

**Payload:**
```json
{
  "token": "{fcm_token}",
  "notification": {
    "title": "Nguyễn Văn A",
    "body": "Bạn có tin nhắn mới"
  },
  "data": {
    "type": "new_message",
    "conv_id": "uuid",
    "message_id": "uuid"
  },
  "android": { "priority": "high" },
  "apns": { "payload": { "aps": { "badge": 5, "sound": "default" } } }
}
```

## 7.3.4 AI Providers

| Provider | API | Model examples |
|----------|-----|----------------|
| OpenAI | `https://api.openai.com/v1/chat/completions` | gpt-4o, gpt-4o-mini |
| Anthropic | `https://api.anthropic.com/v1/messages` | claude-3.5-sonnet |
| Custom | Configurable base_url | Any OpenAI-compatible API |

**NestJS AI Gateway pattern:**
```typescript
// Unified interface, provider-agnostic
interface AIProvider {
  complete(prompt: string, options?: AIOptions): Promise<AIResponse>;
}

// Factory pattern: switch provider based on config
const provider = AIProviderFactory.create(config.provider);
const response = await provider.complete(prompt);
```

**Rate limiting:** Respect provider rate limits. Queue requests via BullMQ if needed.
